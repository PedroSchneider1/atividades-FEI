# Instruções de Desvio
## Saltos Condicionais

### EXEMPLO JZ/JNZ (_JumpZero/JumpNotZero_):
```asm
MOV A, #0 ;ou #1

JZ DESVIO
MOV A, #0
SJMP FIM

DESVIO:
MOV A, #1

FIM:
```

### EXEMPLO CJNE(_CompareJumpNotEqual_):
```asm
MOV A, #11h ;ou #1

CJNE A, #1, ELSE
MOV R1, A

SJMP FIM

ELSE:
MOV R1, #0

FIM:
NOP
NOP
```

## Laços de Repetição

### EXEMPLO DJNZ (_DecrementJumpNotZero_):
```asm
MOV R0, #3

LOOP:
NOP
DJNZ R0, LOOP
```

## Desvios Baseados em Bits

### EXEMPLO JB/JNB (_JumpBit/JumpNotBit_)
```asm
VOLTA:
JNB P2.0, ACENDE
JNB P2.1, APAGA
SJMP VOLTA

ACENDE:
CLR P1.0
SJMP VOLTA

APAGA:
SETB P1.0
SJMP VOLTA
```
